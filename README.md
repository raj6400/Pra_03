# Expense Management System (Pra_03)

A simple C# console application for managing expenses (Add, Display, Remove).

## Description

This project (Pra_03) contains a console-based Expense Management System implemented in C#. It allows adding expenses with ID, category, amount, payment mode, and date; displaying the expense list; and removing expenses by ID.

## How to run

- Open the solution in Visual Studio and run the project.
- Or from command line (if you have the appropriate .NET SDK):

```powershell
cd "d:\MU STUDY\SEM - 05\.Net\Pra_03"
# If this is a .NET Core/5+/6+ project
dotnet run --project Pra_03.csproj
```
